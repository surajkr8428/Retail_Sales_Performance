# Contributing

Thank you for your interest in contributing to the Retail Sales Performance Dashboard. Contributions help improve code quality, documentation, and reproducibility.

## How to Contribute

1. Fork the repository and create a feature branch from `main`:

```bash
git checkout -b feat/your-feature
```

2. Make small, focused changes with clear commit messages.

3. Add or update tests where applicable.

4. Run formatting and linting before opening a pull request.

5. Push your branch and open a PR describing the change and motivation.

## Code Style

- Follow PEP 8 for Python code formatting.
- Use descriptive variable and function names.

## Issues and Feature Requests

- Open an issue to report bugs or request features. Provide a minimal reproduction when possible.
