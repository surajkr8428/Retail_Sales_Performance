# Architecture Overview

This project provides tooling and a Streamlit dashboard for Retail Sales Performance analysis. Structure:

- `src/` — package code (ETL, helpers)
- `scripts/` — runnable scripts for preprocessing and utilities
- `app/` — Streamlit dashboard
- `notebooks/` — exploratory notebooks
- `data/` — raw and processed data (ignored by git)
- `tests/` — pytest tests
- `.github/workflows/` — CI workflows
